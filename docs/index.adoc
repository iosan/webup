== Introduction

Welcome to the WebUp Industrial Engineering documentation. This project is a modern, accessible, and SEO-optimized static website showcasing metal fabrication and industrial engineering projects.

=== Project Overview

WebUp is a professional HTML5/CSS3 website designed for industrial engineering companies specializing in metal fabrication, CNC machining, and manufacturing services.

.Key Features
* Fully responsive design with mobile (≤480px) and tablet (≤768px) breakpoints
* Fixed navigation bar with button-style menu and dropdown
* Active page indicators in navigation
* Accessibility compliant (WCAG standards)
* SEO optimized with meta tags and sitemap
* Privacy compliant (robots.txt, noindex tags)
* Modern CSS with variable-based theming
* Interactive image gallery with paper shadow effects
* Scrolling footer with W3C validator badges

== Navigation System

=== Fixed Top Navigation Bar

The website features a modern fixed navigation bar that stays visible while scrolling:

* **Position**: Fixed at the top of the viewport (z-index: 1000)
* **Logo**: 32px gear logo on the left, links to homepage
* **Menu Items**: Centered button-style links (Home, About, Contact, Projects)
* **Dropdown**: Projects menu reveals links to all 5 project detail pages
* **Active State**: Current page highlighted with background and border
* **Responsive**: Scales down for tablet (28px logo) and mobile (24px logo)

[source,html]
----
<nav class="top-nav" aria-label="Main navigation">
    <div class="logo">
        <a href="index.html" aria-label="WebUp Home">
            <img src="images/gear.png" alt="WebUp Logo">
        </a>
    </div>
    <ul>
        <li><a href="index.html" class="nav-button" aria-current="page">Home</a></li>
        <li><a href="about.html" class="nav-button">About</a></li>
        <li><a href="contact.html" class="nav-button">Contact</a></li>
        <li class="dropdown">
            <button class="nav-button dropdown-toggle" aria-haspopup="true" aria-expanded="false">
                Projects ▾
            </button>
            <ul class="dropdown-menu">
                <li><a href="image1.html">Project 1</a></li>
                <li><a href="image2.html">Project 2</a></li>
                <li><a href="image3.html">Project 3</a></li>
                <li><a href="image4.html">Project 4</a></li>
                <li><a href="image5.html">Project 5</a></li>
            </ul>
        </li>
    </ul>
</nav>
----

=== Button-Style Menu Items

Navigation items are styled as modern buttons with:

* Transparent background with subtle borders
* Padding: 8px vertical, 16px horizontal
* Border radius for rounded corners
* Hover effect: semi-transparent white background
* Focus outline for keyboard navigation
* Active page indicator: darker background and visible border

[source,css]
----
.nav-button {
    color: var(--color-white);
    background: transparent;
    border: 1px solid transparent;
    border-radius: 4px;
    padding: 8px 16px;
    transition: all var(--transition-fast);
}

.nav-button:hover {
    background-color: rgba(255, 255, 255, 0.1);
    border-color: rgba(255, 255, 255, 0.3);
}
----

=== Dropdown Menu

The Projects dropdown provides access to all project detail pages:

* **Hidden by Default**: `display: none`, `visibility: hidden`, `opacity: 0`
* **Activated on Hover**: Uses `:hover` and `:focus-within` pseudo-classes
* **Smooth Transition**: Fades in with opacity transition
* **Elevated**: Box shadow creates depth and separation
* **Accessible**: `aria-haspopup` and keyboard navigation support

[source,css]
----
.dropdown-menu {
    display: none;
    visibility: hidden;
    opacity: 0;
    position: absolute;
    top: 100%;
    left: 0;
    background-color: var(--color-white);
    min-width: 160px;
    box-shadow: 0 4px 8px rgba(0, 0, 0, 0.2);
    transition: opacity var(--transition-fast);
}

.dropdown:hover .dropdown-menu,
.dropdown:focus-within .dropdown-menu {
    display: block;
    visibility: visible;
    opacity: 1;
}
----

== Features in Detail

=== Responsive Design

The website adapts to different screen sizes using:

* **CSS Media Queries**: Two breakpoints at 768px (tablet) and 480px (mobile)
* **Flexbox Layouts**: Flexible navigation and content arrangement
* **Flexible Images**: `max-width: 100%` and explicit sizing for breakpoints
* **Viewport Meta Tag**: Ensures proper mobile rendering
* **Responsive Navigation**: Logo and menu scale down on smaller screens
* **Responsive Typography**: Font sizes reduce at tablet and mobile breakpoints
* **Responsive Images**: Gallery boxes scale from 250px → 180px → 140px
* **Single Column Layout**: Gallery switches to 1 column on mobile

    /* Spacing */
    --spacing-sm: 20px;
    --spacing-md: 40px;
    
    /* Logo */

    /* Gallery */
    --image-size: 250px;
    --image-rotation-large: 6deg;

== Customization Guide

=== Changing Colors

Edit the CSS variables in `css/style.css`:

[source,css]
----
:root {
    --color-primary: #1a3a52;        /* New header/footer color */
    --color-background: #f0f4f8;     /* New background color */
}
----

=== Changing Logo

. Replace `images/gear.png` with your logo (recommended: 80x80px)
. Replace `images/gear.ico` with your favicon
. Update the CSS variable if using different size:
+
[source,css]
----
:root {
    --logo-size: 100px;  /* Adjust as needed */
}
----

=== Adding New Pages

. Create new HTML file in `html/` directory
. Copy structure from existing page
. Update navigation links in all files
. Add to `sitemap.xml` if publicly accessible
. Update `robots.txt` if page should be excluded

=== Modifying Gallery

Change image count or arrangement in `index.html`:

[source,html]
----
<section class="image-gallery" aria-label="Project Gallery">
    <article class="image-container rotate-left">
        <a href="image1.html">
            <img src="images/metal1.jpg" alt="Project 1">
        </a>
    </article>
    <!-- Add more images -->
</section>
----

Rotation classes available:

* `rotate-left` (-6deg)
* `rotate-left-center` (-3deg)
* `rotate-center` (0deg)
* `rotate-right-center` (+3deg)
* `rotate-right` (+6deg)

=== Apache Configuration

If using Apache, add `.htaccess` for security headers:

[source,apache]
----
# Security Headers
Header set X-Frame-Options "SAMEORIGIN"
Header set X-Content-Type-Options "nosniff"
Header set X-XSS-Protection "1; mode=block"
Header set Referrer-Policy "strict-origin-when-cross-origin"

# Enable compression
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/css text/javascript
</IfModule>

# Browser caching
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpeg "access plus 1 year"
    ExpiresByType image/png "access plus 1 year"
    ExpiresByType text/css "access plus 1 month"
</IfModule>
----

== Troubleshooting

=== Common Issues

==== Images Not Loading

*Problem:* Images don't display on live site

*Solution:* Check file paths are relative and case-sensitive

[source,html]
----
<!-- Correct -->
<img src="images/metal1.jpg" alt="Project">

<!-- Incorrect -->
<img src="/images/metal1.jpg" alt="Project">
<img src="Images/Metal1.jpg" alt="Project">
----

==== Fixed Footer Overlapping Content

*Problem:* Footer covers bottom content

*Solution:* Content has `padding-bottom: 100px` to prevent overlap

==== Logo Position Wrong

*Problem:* Logo doesn't align properly

*Solution:* Adjust CSS variables:

[source,css]
----
:root {
    --logo-position-left: 20px;  /* Adjust horizontal position */
    --logo-size: 80px;           /* Adjust size */
}
----

==== Gallery Not Responsive

*Problem:* Images overflow on mobile

*Solution:* Gallery uses `flex-wrap: wrap` by default. Check CSS variables:

[source,css]
----
:root {
    --image-size: 250px;  /* Reduce for smaller screens */
    --gallery-gap: 40px;  /* Reduce spacing */
}
----
