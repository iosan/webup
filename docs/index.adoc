== Introduction

Welcome to the WebUp Industrial Engineering documentation. This project is a modern, accessible, and SEO-optimized static website showcasing metal fabrication and industrial engineering projects.

=== Project Overview

WebUp is a professional HTML5/CSS3 website designed for industrial engineering companies specializing in metal fabrication, CNC machining, and manufacturing services.

.Key Features
* Responsive design for all devices
* Accessibility compliant (WCAG standards)
* SEO optimized with meta tags and sitemap
* Privacy compliant (robots.txt, noindex tags)
* Modern CSS with variable-based theming
* Interactive image gallery with paper shadow effects
* Fixed footer with clean navigation

=== Responsive Design

The website adapts to different screen sizes using:

* Flexbox layouts

WCAG compliance features:

Search engine optimization includes:

* Semantic HTML structure

=== CSS Variables Theming

Easy theme customization through CSS variables:

[source,css]
----
:root {
    /* Colors */
    --color-primary: #3d2f21;
    --color-background: #f4f4f4;
    
    /* Spacing */
    --spacing-sm: 20px;
    --spacing-md: 40px;
    
    /* Logo */
    --logo-size: 80px;
    
    /* Gallery */
    --image-size: 250px;
    --image-rotation-large: 6deg;
}
----

See link:../html/css/themes.md[Theme Variations Guide] for alternative color schemes.

== Customization Guide

=== Changing Colors

Edit the CSS variables in `css/style.css`:

[source,css]
----
:root {
    --color-primary: #1a3a52;        /* New header/footer color */
    --color-background: #f0f4f8;     /* New background color */
}
----

=== Changing Logo

. Replace `images/gear.png` with your logo (recommended: 80x80px)
. Replace `images/gear.ico` with your favicon
. Update the CSS variable if using different size:
+
[source,css]
----
:root {
    --logo-size: 100px;  /* Adjust as needed */
}
----

=== Adding New Pages

. Create new HTML file in `html/` directory
. Copy structure from existing page
. Update navigation links in all files
. Add to `sitemap.xml` if publicly accessible
. Update `robots.txt` if page should be excluded

=== Modifying Gallery

Change image count or arrangement in `index.html`:

[source,html]
----
<section class="image-gallery" aria-label="Project Gallery">
    <article class="image-container rotate-left">
        <a href="image1.html">
            <img src="images/metal1.jpg" alt="Project 1">
        </a>
    </article>
    <!-- Add more images -->
</section>
----

Rotation classes available:

* `rotate-left` (-6deg)
* `rotate-left-center` (-3deg)
* `rotate-center` (0deg)
* `rotate-right-center` (+3deg)
* `rotate-right` (+6deg)

=== Apache Configuration

If using Apache, add `.htaccess` for security headers:

[source,apache]
----
# Security Headers
Header set X-Frame-Options "SAMEORIGIN"
Header set X-Content-Type-Options "nosniff"
Header set X-XSS-Protection "1; mode=block"
Header set Referrer-Policy "strict-origin-when-cross-origin"

# Enable compression
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/css text/javascript
</IfModule>

# Browser caching
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpeg "access plus 1 year"
    ExpiresByType image/png "access plus 1 year"
    ExpiresByType text/css "access plus 1 month"
</IfModule>
----

== Troubleshooting

=== Common Issues

==== Images Not Loading

*Problem:* Images don't display on live site

*Solution:* Check file paths are relative and case-sensitive

[source,html]
----
<!-- Correct -->
<img src="images/metal1.jpg" alt="Project">

<!-- Incorrect -->
<img src="/images/metal1.jpg" alt="Project">
<img src="Images/Metal1.jpg" alt="Project">
----

==== Fixed Footer Overlapping Content

*Problem:* Footer covers bottom content

*Solution:* Content has `padding-bottom: 100px` to prevent overlap

==== Logo Position Wrong

*Problem:* Logo doesn't align properly

*Solution:* Adjust CSS variables:

[source,css]
----
:root {
    --logo-position-left: 20px;  /* Adjust horizontal position */
    --logo-size: 80px;           /* Adjust size */
}
----

==== Gallery Not Responsive

*Problem:* Images overflow on mobile

*Solution:* Gallery uses `flex-wrap: wrap` by default. Check CSS variables:

[source,css]
----
:root {
    --image-size: 250px;  /* Reduce for smaller screens */
    --gallery-gap: 40px;  /* Reduce spacing */
}
----
