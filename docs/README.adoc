=== Build Automation

Generate diagrams and PDFs with the Makefile from the project root:

- `make diagrams` → Render PlantUML to `docs/images/*.png`
- `make pdfs` → Build PDFs for all docs (including `learning.adoc`)
- `make docs` → Both diagrams and PDFs

No local installs? Use Docker alternatives:

- `make docker-diagrams`
- `make docker-pdfs`

See link:BUILD.adoc[BUILD.adoc] for full instructions and prerequisites.
