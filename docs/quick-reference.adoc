== Common Tasks

=== Local Development

[source,bash]
----
# Python HTTP server
cd html && python -m http.server 8000

# Node.js HTTP server
cd html && npx http-server -p 8000
----

=== Update Colors

. Open `html/css/style.css`
. Find `:root` section
. Change color variables
. Save and refresh browser

=== Replace Images

. Add images to `html/images/`
. Name: `metal1.jpg` through `metal5.jpg`
. Recommended size: 250x250px or larger
. Ensure proper licensing

=== Add New Page

. Create `html/newpage.html`
. Copy structure from existing page
. Update navigation in all HTML files
. Add to `html/sitemap.xml`
