== Sources and Regeneration

All diagrams are maintained as PlantUML:

* Sources: `docs/diagrams/*.puml`
* Rendered images: `docs/images/*.png`

Regenerate with either local tools or Docker. From the project root:

* Local: `make diagrams`
* Docker: `make docker-diagrams`

To include diagrams in PDFs or HTML versions of the docs, ensure `:imagesdir: images` is set (as in this file).
