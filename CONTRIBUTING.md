# Contributing to WebUp

Thank you for your interest in contributing to WebUp Industrial Engineering website!

## How to Contribute

### Reporting Issues
- Use the GitHub issue tracker
- Describe the issue clearly
- Include steps to reproduce
- Mention browser and OS version

### Code Contributions

1. **Fork the repository**
2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make your changes**
   - Follow existing code style
   - Maintain semantic HTML structure
   - Keep accessibility features intact
   - Test across multiple browsers

4. **Commit your changes**
   ```bash
   git commit -m "Add: Brief description of changes"
   ```

5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Create a Pull Request**

## Development Guidelines

### HTML
- Use semantic HTML5 elements
- Include ARIA labels for accessibility
- Maintain proper heading hierarchy
- Add descriptive alt text for images

### CSS
- Follow the existing organization (sections with comments)
- Use consistent naming conventions
- Maintain responsive design
- Test on multiple devices

### Accessibility
- Ensure keyboard navigation works
- Maintain ARIA attributes
- Test with screen readers
- Keep color contrast ratios (WCAG AA minimum)

### SEO
- Update meta descriptions when adding pages
- Maintain proper heading structure
- Keep robots.txt updated
- Update sitemap.xml for new pages

### Image Guidelines
- Use properly licensed images only
- Document image sources
- Optimize images for web (compress, appropriate format)
- Provide descriptive alt text

## Code Style

- Use 4 spaces for indentation (HTML/CSS)
- Add comments for complex sections
- Keep files organized
- Remove trailing whitespace

## Testing

Before submitting:
- [ ] Test in Chrome, Firefox, Safari, Edge
- [ ] Test on mobile devices
- [ ] Validate HTML (https://validator.w3.org/)
- [ ] Validate CSS (https://jigsaw.w3.org/css-validator/)
- [ ] Check accessibility (https://wave.webaim.org/)
- [ ] Test keyboard navigation
- [ ] Verify all links work

## Questions?

Feel free to open an issue for questions or discussions.
